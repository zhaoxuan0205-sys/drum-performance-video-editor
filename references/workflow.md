# 同步与验收
## 当前设备配置
- 画面：DJI Action；其机内麦克风音轨只用于定位参考，成片不得使用。
- 声音：罗兰 TD-17 KVX2 内嵌录制 WAV；成片声音以该文件为唯一来源。
- 两台设备独立计时，采样率也可能不同。先处理固定偏移，再用首、中、尾锚点判断是否存在逐渐累积的漂移；不要因为设备型号直接假设需要变速。
## 选择版本
在停顿、操作手机和重新就位附近查看画面，确认正确且完整的一遍。成片不得包含准备、错误演奏或再次操作设备的画面。
## 对齐首鼓
记录三个时间点：
- 音乐开始；
- 视频第一次真实落鼓；
- 外录音频中对应的第一下鼓声。
视频入点计算：
`视频入点 = 第一次视觉接触 -（第一次音频鼓声 - 音频入点）`
这会自然保留音乐开始到首次落鼓之间的前奏。逐帧确认鼓棒接触鼓面或镲片，而不是手臂运动或鼓棒回弹。
## 判断误差
| 现象 | 调整 |
| --- | --- |
| 接触后才听到声音 | 延后画面或提前音频 |
| 先听到声音、随后才接触 | 提前画面或延后音频 |
| 开头、中段、结尾误差一致 | 调整固定偏移 |
| 误差随时间持续增加 | 测量并修正漂移 |
30 fps 的一帧约为 33 毫秒。每次优先按 1–2 帧微调。
整段相关性可能只对齐伴奏，只能在首鼓已通过视觉接触校准后辅助检查漂移。
## 最终验收
- 音乐前奏与首次落鼓的先后关系正确；
- 开头、中段和结尾的关键鼓点同步；
- 没有逐渐增加的漂移；
- 使用外录音频且未叠加相机原声；
- 结尾保留余音，但没有操作设备画面；
- 调色自然，没有明显过曝或滤镜感。
渲染命令必须明确映射外录音轨。导出后用 `ffprobe` 确认成片只有一条音轨；如听感可疑，再将成片音轨与对应的外录片段解码比对，不以主观听感代替音轨来源检查。
