# 电子鼓演奏视频剪辑 Skill
把**电子鼓内嵌录音**和**人物拍摄画面**自动对齐、剪辑成片，方便发布到小红书、抖音等短视频平台。
## 它解决什么问题
拍电子鼓视频时，通常会得到两份素材：
- 相机拍摄的人物画面；
- 电子鼓内嵌录制的高质量音频。
两份素材需要重新同步，还要处理歌曲前奏、错误录制、开头结尾和设备操作画面。这个 Skill 把这些判断整理成一套可重复执行的流程。
## 你可以用它完成
- 从多次录制中选出正确、完整的一遍；
- 保留歌曲前奏，对齐第一次真实落鼓；
- 检查开头、中段和结尾，修正固定偏移或时钟漂移；
- 完全静音相机原声，只使用电子鼓内嵌录音；
- 删除准备、失误和操作设备的画面；
- 轻度提亮并导出适合短视频平台的成片。
## 当前验证设备
- 画面：DJI Action；
- 音频：罗兰 TD-17 KVX2 内嵌录制 WAV。
其他相机和电子鼓也可以使用，每组素材都需要重新检测同步参数。
## 使用方式
将人物视频和电子鼓录音交给 Codex，并说明要使用本仓库中的 `drum-performance-video-editor` Skill。确认同步参数后，可使用附带的渲染脚本生成成片。
详细流程见 [`SKILL.md`](SKILL.md)，同步判断方法见 [`references/workflow.md`](references/workflow.md)。
